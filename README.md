# Cartera de Acciones 2026 - EE.UU. 📈

Sistema de administración de cartera de inversiones bursátiles en tiempo real, desarrollado para PC, Tablet Android e iPhone (iOS).

## 🚀 Características principales
- **Cotizaciones en vivo de la Bolsa de EE.UU.** (NYSE / NASDAQ).
- **Tablero de gestión** con gráficos intradiarios (cada 30 min) y resumen de métricas clave.
- **Registro de Compras y Ventas** con cálculo de acciones fraccionadas (`Monto Invertido / Precio por Acción`).
- **Base de datos SQLite persistente** con historial completo de transacciones.
- **Noticias financieras en español** con ventanas emergentes de resumen interno.
- **Soporte PWA e iOS**: Instalable directamente en iPhone y Tablet Android.
